# Estuscia Group — immersive site (React + TypeScript + Vite + Three.js + GSAP)

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # outputs /dist

Edit **src/content.ts** to add verified copy, business areas, contact email, legal and social links.
Zoom transitions live in **src/hooks/useChoreography.ts**; the 3D scene in **src/scene/Scene.tsx**.
